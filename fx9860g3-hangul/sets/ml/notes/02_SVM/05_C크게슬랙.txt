C 크기 효과
이럴때: C 크게, C 작게
C 큼: 마진 좁음, 오분류 거의 불허
C 작음: 마진 넓음, 오분류 허용
극한 C→∞ 는 하드마진
주의: C 큼=과적합, 작음=과소적합
---
슬랙 xi 계산 (힌지)
이럴때: y×f(x)=0.4, 슬랙, 힌지
xi=max(0, 1-y×f(x))
yf=0.4 → xi=0.6 (마진 침범)
yf=-0.5 → xi=1.5 (오분류)
yf≥1 → xi=0
---
소프트마진 목적함수
이럴때: 슬랙 변수, 제약 수정
최소화: 1/2×w크기²+C×∑xi
제약: y(wx+b)≥1-xi, xi≥0
0<xi<1 침범, xi≥1 오분류
주의: C×∑xi 항이 오차 벌점
