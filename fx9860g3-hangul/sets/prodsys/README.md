# 생산시스템공학 v4 시험장 노트 (fx-9860G III .g1a)

## 폴더
- 0 객관식 색인 (F2) : 선지 키워드 → 개념 쪽
- 1 서술형 색인 (F3) : 문제 키워드 → 답안 쪽
- 2 객관식개념 : 8개 파일
- 3 서술형 : 문제 유형별 파일, 한 유형당 한 파일

## 사용법
1. 시험지 문장에서 키워드를 찾는다 (예: 신뢰도, 부품전개, 비김점)
2. 색인에서 `키워드(소키워드)`로 찾는다. 같은 키워드에 여러 유형이 있으면 소키워드로 갈라져 있다
   예) 신뢰도(정의) / 신뢰도(계산 순서) / 신뢰도(혼합 구조) / 신뢰도(향상 방안 답안)
3. 각 파일 첫 쪽 = 핵심요약. 이 문제가 맞는지 바로 확인
4. 다음 쪽부터 답안(길이 구분 없이 한 벌), 계산은 식 → 순서 → 예제 → 함정
5. 마지막 쪽 `관련 문서`로 연관 문제 이동

## 표시
- `교재밖:` 교재에 없는 보충 (6줄)
- `불확실:` 없음
- 노트 안에는 장·절·그림 번호를 쓰지 않음. "그림"은 시험지 그림만 뜻함
