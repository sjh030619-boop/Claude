# 생산시스템공학 v3 시험장 노트 (fx-9860G III .g1a)

## 폴더
- 0 객관식 색인 (F2/F3) : 문제 보고 → 개념 찾기
- 1 서술형 색인 : 문제 유형 → 모범답안 찾기
- 2 객관식개념 : 8개 파일 (선지 요령, 정의, 분류, 계획 용어, 신뢰도 등)
- 3 서술형 : 문제 유형별 파일, 한 유형당 한 파일

## 사용법
1. 색인(0 또는 1)에서 문제 키워드를 찾아 링크로 이동
2. 각 파일 첫 쪽의 `이럴때:`로 맞는지 확인
3. 순서: 형태 → 핵심 식 → 풀이 순서 → 숫자 예제 → 함정
4. 마지막 쪽 `관련 문서`로 연관 개념 이동

## 표시
- `교재밖:` 교재에 없는 보충 (6줄)
- `불확실:` 없음

## 범위
- 1장 ~ 8.3절 (8.4 최적경로 DP, 8.5 라인밸런싱 제외)
