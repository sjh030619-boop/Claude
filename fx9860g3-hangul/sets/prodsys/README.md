# 생산시스템공학 v6 시험장 노트 (fx-9860G III .g1a)

## 폴더
- 0 객관식 색인 (F2) : 선지 키워드 → 개념 쪽
- 1 서술형 색인 (F3) : 문제 키워드 → 답안 쪽
- 2 객관식개념 : 8개 파일
- 3 서술형 : 문제 유형별 파일 (57~62 반복 출제 BOM 문제, 63 생산계획 3단계)
- notes/figures/ : 그림 16개 (흑백 PNG, 폭 122px 이하, 높이 44px 이하)

## 사용법
1. 시험지 문장에서 단어를 찾는다 (첫 단어, 영어 표현, 제품 이름 모두 색인에 있음)
2. 색인에서 `키워드(소키워드)`로 찾는다. 같은 키워드의 여러 유형은 소키워드로 갈라져 있다
3. 각 파일 첫 쪽 = 핵심요약 (이 문제가 맞는지 확인)
4. 다음 쪽부터 답안, 계산은 식 → 순서 → 예제 → 함정
5. 마지막 쪽 `관련 문서`로 연관 문제 이동

## 반복 출제 BOM 문제 (3/57~3/62)
시험지 BOM과 재고가 노트 조건과 같으면 답 쪽을 그대로 쓰고, 숫자가 다르면 일반식 쪽에 대입한다.
쪽 순서: 핵심요약 → 조건:BOM → 조건:재고(세트별) → 숫자가 바뀌면(일반식) → 답(세트별) → 답안 쓰는 법.

| 파일 | 문제 | 재고 세트 |
|---|---|---|
| 3/57 | Roller blade (켤레) | A 250켤레·Screw 1000 / B 250켤레·Screw 800 / C 200켤레·Screw 200 |
| 3/58 | 안경테 1000개 | 1세트 |
| 3/59 | 롤 아이템 합성(삼위일체형) 50개 | 1세트 |
| 3/60 | 롤 아이템 트리(선혈포식자형) | A 50개 / B 세 품목 각 10개(해석 가정) |
| 3/61 | 의자 1000개 (구성 그림) | 1세트 |
| 3/62 | 선풍기 조립도 → BOM | BOM 작성만 |

## 그림 쪽 (시험 제시 그림)
같은 파일 안에서 ① 그림 쪽(제목+그림+설명) → ② 답 쪽(읽는 법, 풀이, 답) → ③ 변형 쪽(이렇게 보이면 → 이렇게 답) 순서.
그림 쪽에는 답이 없고 다음 쪽부터 답이 나온다.

| 파일 | 그림 | 내용 |
|---|---|---|
| 3/06 BOM | BOM 트리, 조립도 | 트리 → 단일수준 표, 실선 박스 = 중간 조립품 |
| 3/61 의자 | 의자 구성 | 구성 그림 → BOM → 부품전개 |
| 3/12 신뢰도계산 | 혼합 구조, 두 줄 병렬 | 병렬 묶음 먼저, 나머지 직렬 곱 |
| 3/26 흐름도 | 빈칸 양식 | 칸 1~5, 화살표 a~c 이름 |
| 3/51 Opitz 읽기 | 부품 도면 5종 | 나사 축 16100, 기어 슬리브 12105, 플랜지 12102, 모터형 14002, 부품 2개 12100/15100 |
| 3/53 오른손-왼손 | 볼펜 부품 | 조립 순서 → 공정도 표 |
| 3/10, 3/21, 3/52, 3/54 | 답으로 그리는 그래프 | PLC 곡선, 규모의 경제, 비김점, 학습곡선 |

## 표시
- `교재밖:` 교재에 없는 보충 (6줄)
- `불확실:` 그림·스캔 판독이 불확실한 곳 (9줄)
- 노트 안에는 장·절·교재 그림 번호를 쓰지 않음. "그림"은 시험지 그림 또는 노트 그림
