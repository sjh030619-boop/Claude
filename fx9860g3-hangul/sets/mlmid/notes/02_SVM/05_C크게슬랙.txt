C 를 크게 문제
이럴때: 소프트 마진 SVM에서 C
를 크게 하면
연관: →2/04 →2/07
1) 마진이 넓어지고 오분류를 더
  허용
---
C 를 크게 선지
2) 마진이 좁아지고 오분류를
  거의 허용하지 않음
3) 마진과 무관
4) 모든 점이 서포트 벡터가 됨
---
C 를 크게 풀이
답: 2)
C 큼: 슬랙 벌점이 큼
→ 오분류 거의 불허, 마진 좁음
C 작음: 마진 넓고 오분류 허용
C→∞ 는 하드 마진
---
슬랙 힌지 손실 문제
w, b 로 계산한 yf(x) = 0.4 인
점의 슬랙 ξ (힌지 손실)는 yf(x)
= -0.5 이면
1) 0, 0
2) 0.6, 1.5
---
슬랙 힌지 손실 문제 (계속)
3) 0.6, 0
4) 0.4, 0.5
---
슬랙 힌지 손실 풀이
답: 2) 0.6, 1.5
ξ=max(0, 1-y f(x))
yf=0.4: ξ=1-0.4=0.6
yf=-0.5: ξ=1+0.5=1.5
0<ξ<1 침범, ξ≥1 오분류
---
소프트 마진 식
최소화 1/2‖w‖²+C∑ξ_{i}
제약 y_{i}(w^{T}x_{i}+b)≥1-ξ_{i}
ξ_{i}≥0
주의: C 큼=과적합, 작음=과소
