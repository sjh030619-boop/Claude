H(P,Q)와 KL 문제
이럴때: 정답 분포 P = (1, 0),
모델 예측 Q = (0.8, 0.2) 일 때
교차 엔트로피 H(P, Q)
(자연로그)와 D_{KL}(P‖Q) 는
연관: →4/03 →3/06
---
H(P,Q)와 KL 선지
1) 0.223, 0.223
2) 0.223, 0
3) 0.8, 0.2
4) 0, 0.223
---
H(P,Q)와 KL 풀이
답: 1) 0.223, 0.223
H(P,Q)=-∑P ln Q=-ln0.8
=0.223
H(P)=0 (P=(1,0))
KL=H(P,Q)-H(P)=0.223
---
H(P,Q)와 KL 풀이 (계속)
주의: ln0.8≈-0.223
---
KL 틀린 설명 문제
KL divergence 에 대한
설명으로 틀린 것은
1) 항상 0 이상이다.
2) 두 분포가 같으면 0 이다.
---
KL 틀린 설명 문제 (계속)
3) D_{KL}(P‖Q) = D_{KL}(Q‖P) 가 항상
  성립한다.
4) H(P, Q) = H(P) + D_{KL}(P‖Q)
  이다.
---
KL 틀린 설명 풀이
답: 3)
KL 은 비대칭이다
D_{KL}(P‖Q)≠D_{KL}(Q‖P)
1) 0 이상 2) P=Q 이면 0 참
4) H(P,Q)=H(P)+KL 참
