# 기계공학을위한인공지능 중간고사 계산기 노트

구성: 폴더 01~06 (본문), 00 (색인). 과제 39문항은 문제 전문과 선지를 그대로 넣고 풀이 쪽을 붙였다.
각 파일 첫 쪽의 "이럴때:" 줄은 문제 지문 전문이고, 같은 문제를 다르게 낸 변형은 풀이 쪽의 공식과 절차로 푼다.
"교재밖:" 은 교안에 없는 내용, "불확실:" 은 교안 근거가 불확실한 내용이다.
