구성: 00 객관식색인, 01 서술형색인, 02 제시예제객관식, 03 제시예제서술형, 04 예제풀이, 05~10 객관식과 개념, 11 서술형.
- v10: 제시 예제 쪽을 계산 탭 형식으로 (제목만, 이럴때·유형 표시 없음, 끝에 @계산 / @식 / @추가). 바뀔 숫자는 ㉠~㉭ 변수 바로 뒤에 원래 값. 예제풀이는 같은 변수와 {=식} 결과, 쪽마다 @값.
- v9: 제시 예제 = 과제1 39문항(02), SVM 추가 과제 3문항, 3점 선긋기 예제, 병 공 확률, 이항분포, 1-1-1 역전파 예제(03). 문제 하나가 한 쪽이다.
- 제시 예제 쪽: 1줄 [개념]/[숫자]/[계산]/[서술] 유형, 2줄 이럴때: 문제, 3~5줄 조건과 선지, 6줄 '추가 정보' (누르면 04 예제풀이).
- 선지 번호는 ①~④, 정답은 ❶~❹. [숫자] 문제는 바뀔 수 있는 자리를 ㉠㉡㉢ 로 쓰고 원래 값을 바로 뒤에 붙였다 (예: ㉠3). 식에 새 숫자를 넣으면 답이 나온다.
- 04 예제풀이: 01~39 객관식(정답과 풀이, 대입 틀 또는 계산 과정, 숫자 바꾼 예, 오답 이유, 예상 선지), 40~46 서술형(문제와 답, 단계 풀이, 변형). 끝쪽 관련 문서에서 '문제로 돌아가기'와 개념 노트로 이동한다.
- 아래 v5~v8 설명의 폴더 번호는 v9 에서 3 씩 밀렸다 (예: 08/10 → 11/10).
- 객관식과 서술형은 완전히 분리했다. 02~07 파일의 링크는 02~07 안에서만, 08 파일의 링크는 08 안에서만 이어진다 (교차 링크 0).
- 색인은 F2 키로 객관식색인(00), F3 키로 서술형색인(01)이 열린다. 둘 다 가나다순이다. 서술형색인은 단계 이름까지 구체적으로 적었다.
- 모든 파일의 마지막 쪽은 "관련 문서" 쪽이다. "제목 →폴더/파일:쪽" 한 줄에 링크 하나씩 최대 4줄이고, 계산기에서는 제목만 보이고 선택된다.
- v5 보강: 05/06 거리코사인놈(교안 2단원: 유클리드 거리, 코사인 유사도, L1 L2 놈), 06/07 규제항L1L2(교안 규제 + 교재밖 L1 L2), 08/01 은닉 2층 벡터 예제와 가중치 크기·파라미터 수 정리.
- v6: 표 기능(│) 적용 — 07/05 결측 유형, 05/06 벡터 놈, 03/04 소프트 마진 α, 02/04 층별 활성화.

- 출처 대응: 02 MLP=신경망 역전파, 03 SVM=4단원+보충, 04 회귀분류=3단원·최적화, 05 확률정보=2단원 확률·정보이론·거리, 06 개요모델선택=1단원, 07 전처리=2단원 전처리·차원축소.

- 각 파일 끝에는 "선지 변형" 또는 "변형" 쪽이 있다. 같은 개념이 선지로 바뀌어 나올 때 참/거짓과 값 변형을 본다.
- 08 서술형: 역전파(층 늘림), SVM 선 긋기, 유도 서술, 과잉적합과 전처리 서술, 답안 문장 틀, 소문항 계산틀(08/09), SVM 판정·역산(08/10), 확률 계산(08/11).
- 소문항(단계별 계산): 08/01, 08/02 의 '소문항 대응' 쪽과 08/09 소문항계산틀을 본다.
- "교재밖:" 은 교안에 없는 내용, "불확실:" 은 교안 근거가 불확실한 내용이다. "▽" 는 한 쪽 안에서 주제가 바뀌는 곳이다.
- 근거: 수업 녹취(역전파 예제, 기울기 -2, 학습률 1/4), ch4 보충(SVM 3점 예제). 보충 13쪽의 내부 정지점은 자료에 α2=-1, α3=1 로 되어 있으나 계산하면 α2=1.5, α3=-1 이다 (결론 α=(0.25,0.25,0) 은 같음).
