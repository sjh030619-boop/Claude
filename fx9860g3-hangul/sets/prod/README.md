# 계산기 노트 v4 안내

## 구조
- `00_색인`: 문제에 나오는 표현 가나다순 -> 파일과 쪽. 쪽 제목 `[색인 가-나]`는 그 쪽의 첫 글자 범위.
- `01`~`15`: 주제 폴더. 파일 첫 쪽에만 `이럴때:`(문제 문장 키워드)와 `연관:`(같이 볼 파일 링크)이 있음.
- 링크 `→7/03:2` = 7번 폴더 03번 파일 2쪽. 쪽 생략 = 1쪽.

## 풀이 순서
1. 문제의 표현을 색인에서 찾는다. 2. 해당 파일 1쪽의 `연관:`으로 함께 써야 할 개념 확인. 3. 답안 쪽을 그대로 옮겨 쓴다.
