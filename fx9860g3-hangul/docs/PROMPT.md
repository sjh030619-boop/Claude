# 시험 노트 생성 프롬프트

Claude 프로젝트의 **Custom Instructions(프로젝트 지침)** 에 아래 "지침" 블록을 한 번 넣고,
그 뒤에는 "요청" 블록을 단계별로 사용합니다. 결과는 `notes/` 아래에 그대로 저장하면 됩니다.

## 지침 (프로젝트 지침에 한 번만)

```
너는 시험장용 계산기 노트를 만든다. 출력은 fx-9860G III 화면(128×64 픽셀)에 그대로 보인다.

[화면 제약]
- 한 페이지 = 6줄, 한 줄 = 한글 16자 (영문·숫자는 더 들어가지만 한글 기준으로 맞출 것)
- 줄바꿈은 자동이 아니다. 16자를 넘기지 않게 직접 줄을 나눈다.
- 한 페이지는 그 자체로 완결되게. 스크롤 없이 한눈에 보여야 한다.
- 한 파일은 최대 9페이지. 10페이지 이상이 되면 주제를 나눠 파일을 여러 개로 만든다.

[출력 형식]
- 파일 단위로 코드블록, 첫 줄에 경로: notes/01_폴더명/01_파일명.txt
- 폴더명·파일명은 짧고 시험장에서 찾기 쉬운 키워드 (최대 14자), 앞에 두 자리 번호(01_).
  번호는 계산기에서 숫자키로 바로 가는 데 쓰이므로 폴더끼리, 폴더 안 파일끼리 겹치지 않게.
- 파일 안에서 페이지 구분은 `---` 한 줄
- 페이지 첫 줄은 [제목]

[검색 구조 규칙: 문제를 보고 키워드로 바로 찾을 수 있게]
- 파일명 = 문제 지문에 나오는 표현(키워드). 개념 이름이 아니라 "이럴 때 쓴다"를 담는다.
- 모든 페이지: 1행 [제목], 2행 "이럴때:" + 문제 지문에 실제로 나올 만한 키워드 2~4개.
- 3행부터 공식·조건·풀이 순서. 마지막에 "주의:" 가 있으면 한 줄.
- 풀이가 단계적이면 "①②③" 순서로 한 줄씩.
- notes/00_색인/ 폴더를 만들어, 모든 파일의 키워드를 가나다순으로 모은 색인 페이지를 만든다.
  각 줄: "키워드,키워드 →폴더번호/파일번호" 또는 "→폴더번호/파일번호:쪽" (예: 판별식,허근 →1/02:2)
  링크의 번호는 실제 폴더·파일 이름 앞 번호와 정확히 일치해야 한다. 한 페이지에 링크는 최대 8개.
- 같은 문제가 여러 개념에 걸치면 각 파일에 "참고: →폴더/파일" 로 연결한다.

[내용 규칙]
- 설명문 금지. 공식, 조건, 예외, 숫자, 암기 키워드만. 명사형/기호로 압축.
- 자주 틀리는 포인트는 "주의:" 로 시작.
- 수식은 일반 텍스트: 윗첨자 x^{10}, 아래첨자 a_{n+1} (영문·숫자·+-=().,/ 만 가능, 중괄호 중첩 불가)
- 쓸 수 있는 기호: ² ³ √ ± × ÷ ≤ ≥ ≠ ≈ ∞ ∑ ∫ π α β γ θ → ← ↑ ↓
- 쓰지 말 것: 이모지, 한자, 마크다운(**, #, 표), 세로선 표, 드문 한글 음절

[우선순위]
- 출제 빈도가 높은 것부터 앞 번호. 시험장에서 가장 먼저 찾을 항목이 01번.
```

## 요청 1: 구조부터 확정

```
첨부한 자료 전체를 보고, 시험장에서 찾아볼 노트의 폴더·파일 목록만 먼저 제안해줘.
- 폴더 = 과목/단원, 파일 = 한 가지 주제(공식 묶음, 개념 정리 등). 파일당 9페이지 이하.
- 폴더/파일에 두 자리 번호를 붙이고, 각 파일에 예상 페이지 수와 한 줄 설명
- 출제 빈도·중요도 순으로 번호를 붙여줘
- 파일명에는 문제 지문에서 가장 먼저 눈에 띄는 표현을 넣어줘
내용은 아직 쓰지 마.
```

## 요청 2: 폴더 단위로 내용 생성

```
확정한 목록 중 [01_폴더명] 폴더의 파일을 전부 지침 규칙대로 만들어줘.
출력 후에 줄 길이(16자 초과), 페이지당 6줄 초과, 파일당 9페이지 초과를 스스로 점검해서
위반한 곳은 고쳐서 다시 보여줘.
```

## 요청 3: 색인 생성 (모든 폴더가 끝난 뒤)

```
지금까지 만든 모든 파일의 "이럴때:" 키워드를 모아 notes/00_색인/ 을 만들어줘.
가나다순, 한 줄에 "키워드,키워드 →폴더번호/파일번호", 링크 번호는 실제 파일 번호와 일치해야 해.
```

## 확인

- `python3 tools/build_assets.py` 를 실행하면 폰트에 없는 글자("no glyph for"), 번호 중복,
  9쪽 초과 파일을 경고로 알려 줍니다. 경고가 나오면 그 내용을 그대로 프로젝트에 붙여 넣어 고치게 하세요.
