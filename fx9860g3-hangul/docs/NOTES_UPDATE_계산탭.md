# 노트 프로젝트에 보낼 것 (계산 탭 형식 적용)

## 첨부할 파일 (2개)
1. `docs/PROJECT_PROMPT.md` — 프로젝트 지침을 이 내용으로 교체 (계산 탭·풀이 채우기 규칙 포함)
2. `docs/check_bundle.zip` — 새 검사기 (calcpage.py 포함, 기존 번들을 이걸로 교체)

## 붙여 넣을 요청 문장
```
기계공학을위한인공지능 노트(notes-v9)의 제시 예제 쪽을 새 "계산 탭" 형식으로 다시 만들어 줘.
첨부한 새 지침(PROJECT_PROMPT.md)과 새 검사기(check_bundle.zip)를 먼저 적용해.

바꿀 것
1. 제시예제(02 객관식, 03 서술형) 모든 문제 쪽:
   - 첫 줄은 제목만 쓰고 [숫자] [개념] [계산] 같은 유형 표시는 빼. "이럴때:" 줄도 쓰지 마.
   - 문제와 선지(①~④, 정답은 ❶~❹)는 한 쪽에 두고, 쪽 끝에 지시줄을 써:
       @계산
       @식 이름=식        (숫자를 바꾸면 바로 답이 나오는 식, 여러 줄 가능)
       @추가 →폴더/파일:쪽  (예제풀이의 해당 풀이 첫 쪽)
   - 시험에서 숫자만 바뀌어 나올 자리는 원문자 변수(㉠㉡㉢…, 쪽당 8개 이하) 바로 뒤에 원래 숫자를 붙여 써.
     예: A:(㉠0.5,㉡0.6)  J=(w-㉠3)²  w0=㉡0  α=㉢0.1   (화면에는 숫자만 보임)
   - 개념 문제처럼 계산이 없으면 지시줄 @계산 (+ @추가)만 써도 돼.
   - 이 쪽은 본문 56px 이하(5줄), 본문에 → 링크 금지, 변수 8개 이하.
2. 예제풀이(04) 쪽:
   - 문제 쪽 @추가 가 가리키는 쪽부터 그 파일 끝까지가 "계산" 입력 후 새 숫자로 채워져 보여.
   - 풀이 쪽에도 같은 변수를 숫자와 함께 쓰고(값은 문제 쪽과 같게), 계산 결과 자리는 {=식}으로 써.
     예: J'=2(w-㉠3)=2(㉡0-㉠3)   ={=2(㉡-㉠)}     (식 안은 변수 문자만)
   - 풀이 쪽마다 맨 끝에 @값 한 줄. (탭 줄이 없으니 높이 64px, 링크 OK. "문제로 돌아가기" 링크는 그대로 둬)
   - 숫자가 바뀌어도 맞는 풀이가 되게 변수로 만들 수 있는 숫자는 전부 변수로.
3. 색인·링크·폴더 구조는 v9 그대로 유지 (번호가 바뀌면 링크도 같이).

검증
- 새 검사기로 E 0, W 0 이 될 때까지 고쳐 (python3 check_notes.py --dir <notes>).
- 검사기가 출력하는 "계산 탭 식" 결과(원래 값으로 계산한 값)가 각 문제의 정답과 맞는지 확인하고,
  틀린 식은 고쳐서 다시 검사해.
- 납품 때 문제 수, 변수/식이 들어간 쪽 수, 검사 결과를 알려 줘.
```

## 받은 뒤 할 일 (이 세션)
zip 을 `sets/mlmid/` 에 적용 → `python3 tools/check_notes.py --set mlmid` → 푸시 → 빌드 → .g1a 전달.
