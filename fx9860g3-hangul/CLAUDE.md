# fx-9860G III Hangul notes add-in

Builds CASIO fx-9860G III add-ins (`mlmid.g1a`, `prodsys.g1a`, ... one per subject/note set) that show Korean notes.

**Taking over this project (new computer / new Claude account): read `docs/HANDOVER.md` first.**

## Common tasks

- **Build the add-in (Windows, via WSL2 Ubuntu)**: `powershell -ExecutionPolicy Bypass -File tools\windows\build_windows.ps1`
  Output: `dist\<name>.g1a`, one per note set (`python3 tools/noteset.py list`). The toolchain (sh-elf-gcc, fxSDK, gint) is already installed in WSL after
  the first run, so later builds take a few minutes. On failure, show the last ~30 lines and the `[n/5]` step.
- **Check notes before building**: `python3 tools/check_notes.py` (all sets; must report 0 errors).
- **Optional**: `python3 tools/split_notes.py --set <id> [--write]` splits long files (no page limit exists; also fixes links).
- **Regenerate data for one set**: `python3 tools/build_assets.py --set <id>` (writes `src/font_data.c`, `src/notes.c`,
  `src/addin.cmake`; these are gitignored because they depend on the set).
- **Deliver the result**: send the user the `dist\*.g1a` files; they copy it to the calculator in
  Mass Storage mode (`MENU` -> `LINK`).

## Layout

- `sets/<id>/set.json` (`name` = add-in name, <= 8 ASCII chars) + `sets/<id>/notes/<NN_folder>/<NN_file>.txt` -
  exam notes of one subject; pages are split by a `---` line; names start with a two-digit number used for
  number-key jumps. Index folders (`00`, or any folder whose name contains "색인"; at most two: F2 = first, F3 = second) are merged into one document each. Links never cross sets.
- Links inside notes: `→folder/file` or `→folder/file:page`. Pages with links are menu pages
  (UP/DOWN select, EXE follows). A line with exactly one link is selected as a whole line; if it has a title in front of the token (not a label ending in ':'), the `→f/n:p` token is not drawn, so link-line width is measured without it. Lines with several links keep visible tokens and per-token underline. Formula lines (any line containing `$`; `$...$` with `{num;den}` fractions and 7px `_{..}`/`^{..}` scripts) are 22 px tall and never wrap; a page's height (10 px per normal line + 22 px per formula line) must be <= 64 px; `hg_line_y` maps a line index to its y. In formula lines `√{..}`, `∑_{lo}^{hi}` and a combining U+20D7 arrow are also drawn. Table rows (lines with U+2502 `│` between cells; consecutive rows = one table, drawn with frame and rules, 11 px per row + 1 px) are laid out by `table_group` in hangul.c and checked by check_notes.py. Figure lines (`[그림 name]` = a whole line; `notes/figures/name.png`, black on white, <= 128x64) are turned into 1-bit bitmaps by build_assets.py (`apply_figures`, line text becomes 0x1F + 3 digits) and drawn by `draw_fig` in hangul.c; `tools/fig_tool.py` converts arbitrary images. Key `EXP` in lists and the viewer opens a small real calculator (src/calc_eval.c = parser/format following the fx-9860GIII manual, src/calc_ui.c = screen, src/calc_font.c = Casio 5x7 system font generated by tools/make_calc_font.py, bottom function-key bar copied from fakecalc_data.c; host test tools/calc_test.c). Problem pages may end with `@계산` / `@식 label=expr` / `@추가 →f/n:p` directive lines (tools/calcpage.py; parsed by build_assets into `hg_pageinfo`, drawn as F1 추가 / F2 계산 tabs in main.c, calculation tab = src/note_calc.c; body <= 56 px, no links in body). Folders whose name contains `제시예제` are merged into one document at build time (links rewritten by `remap` in build_assets.py); bare `^x`/`_x` scripts are wrapped to `^{x}`/`_{x}` by `calcpage.script_wrap`. The add-in calls `gint_setrestart(1)` in main(); its menu icon is generated per set from `sets/<id>/icon.json` (tools/make_icon.py). Link pages must keep every line <= 122 px,
  other pages <= 128 px. Folder 00 (index) is merged at build time into one document with an auto table of
  contents and 초성 range titles (`merge_index` in tools/build_assets.py); F2 reopens it where you left it.
- `src/` - add-in source (gint). `tools/sim/` - PC simulator (stub gint) used to test navigation:
  see README ("PC 에서 동작 시뮬레이션").
- `docs/PROMPT.md` - instructions for the Claude project that writes the notes.

## Rules of thumb

- Never edit `src/font_data.c`, `src/notes.c`, `src/addin.cmake`, `src/fakecalc_data.c` by hand (generated).
- Screen is 128x64 px, 7px Korean bitmap font (Galmuri7): 6 lines per page; no page limit per file
  (a `page/total` indicator is drawn top-right when the first line leaves room).
- The git host for fxSDK moved to `git.planet-casio.com` (the old `gitea.planet-casio.fr` no longer resolves).
