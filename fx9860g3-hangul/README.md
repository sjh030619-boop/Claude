# fx-9860G III 한글 뷰어 (add-in)

> 새 컴퓨터/새 Claude 계정에서 이어서 작업하려면 [`docs/HANDOVER.md`](docs/HANDOVER.md) 를 먼저 읽으세요.

계산기 화면에 한글을 보여주는 fxSDK/gint add-in 입니다. Galmuri(기본 7px 한글 픽셀폰트, SIL OFL)를
비트맵으로 내장해서 128×64 화면에 **16글자 × 6줄** 정도를 표시합니다.

## 쓰는 법 (과목마다 앱 하나: 노트 세트)
과목별로 **노트 세트**를 만들고, 세트마다 `.g1a` 를 하나씩 만듭니다. 계산기 메뉴에서 과목 앱을 골라 실행합니다.
```
sets/
  mlmid/                   ← 세트 id (아무 이름)
    set.json               ← {"name": "mlmid", "title": "기계공학을위한인공지능"}   name = 계산기 메뉴의 앱 이름(영문 8자 이하)
    notes/<NN_폴더>/<NN_파일>.txt
  prodsys/
    set.json  notes/...
```
1. 글은 `sets/<세트>/notes/<폴더>/<파일>.txt` (UTF-8) 로 둡니다. 계산기에서 폴더 → 파일 → 본문 순서로 열립니다.
   - 한 파일 안에서 `---` 한 줄이 페이지 구분입니다.
   - 이름 앞의 숫자(`01_`)는 정렬·번호 점프용이고, 폴더 `00` 은 색인입니다.
   - 새 과목: `sets/<새id>/set.json` 과 `notes/` 를 만들면 됩니다. 출력 파일은 `<name>.g1a` (예: `mlmid.g1a`).
2. 노트 검사 / 데이터 생성 (세트 하나 기준):
   ```
   python3 tools/check_notes.py                    # 모든 세트 검사 (--set <id> 로 하나만)
   python3 tools/build_assets.py --set prodsys        # 폰트 + 노트 데이터 + 앱 이름 생성 (기본 7px)
   python3 tools/build_assets.py --set prodsys --only-used   # 쓴 글자만 (훨씬 작음)
   python3 tools/build_assets.py --set prodsys --font 11     # 11px 폰트 (10글자 × 5줄)
   ```
   생성되는 `src/notes.c`, `src/font_data.c`, `src/addin.cmake` 는 세트마다 달라서 git 에 올리지 않습니다.
3. 빌드 ([fxSDK](https://git.planet-casio.com/Lephenixnoir/fxsdk) 필요) — 세트마다:
   ```
   python3 tools/build_assets.py --set prodsys && fxsdk build-fx     # → prodsys.g1a
   ```
   Windows 스크립트(아래)는 모든 세트를 차례로 빌드해서 `dist/` 에 `.g1a` 를 여러 개 만듭니다.
4. `.g1a` 들을 USB 로 계산기 저장 메모리에 복사합니다.

### 파일 쪽수
쪽수 제한은 없습니다. 본문 오른쪽 위에 `현재쪽/전체쪽` 이 보이고(첫 줄에 자리가 없으면 생략), ← → 로 넘기고,
숫자키(두 자리까지)로 쪽 번호로 바로 갑니다. (`tools/split_notes.py` 는 파일을 일부러 쪼개고 싶을 때 쓰는
선택 도구입니다: `--set <id> [--write]`, 링크 번호도 같이 고치고 분할 전후 링크가 같은 페이지를 가리키는지 검증합니다.)

### 색인 (폴더 00 / 이름에 "색인" 이 들어간 폴더)
색인 폴더는 최대 둘까지 쓸 수 있습니다(예: `00_객관식색인`, `01_서술형색인`). 번호 순으로 첫째가 **F2**, 둘째가 **F3** 입니다.
색인 폴더의 모든 파일·쪽은 빌드할 때 **하나의 이어진 문서**로 합쳐집니다.
- 맨 앞에 자동 **초성 목차**가 붙습니다: `ㄱ 3  ㄴ 10  ㄷ 10 …` (그 글자가 시작되는 쪽). 쪽 번호를 숫자키로 누르세요.
- 각 쪽 제목이 자동으로 `색인 ㄱ 각~계` 처럼 바뀌어, 그 쪽이 ㄱ~ㅎ(A~Z) 중 어디인지 알려 줍니다.
- 색인은 ← → 로 계속 넘어가고(파일 경계 없음), **F2**(첫째 색인)·**F3**(둘째 색인) 은 목록·본문 어디서든 그 색인을
  **마지막으로 보던 쪽**에서 바로 엽니다. 색인 안에서 같은 키를 다시 누르면 목차(1쪽)로 갑니다. 문서가 하나뿐인 폴더는 파일 목록 없이 바로 열립니다.
- 링크 줄 앞에 `>` 가 뜨고 EXE 로 이동합니다. **한 줄에 링크가 하나**면 줄 전체가 선택되어 밑줄이 그어지고(`표현 →3/05:2`),
  앞에 제목 글자가 있고 `:` 로 끝나는 레이블(`연관:`)이 아니면 `→3/05:2` 토큰은 화면에 **그리지 않습니다**(제목만 보임).
  한 줄에 링크가 여러 개면(`연관: →8/02 →8/03`) 토큰이 보이고 선택된 토큰에만 밑줄이 그어집니다.

## 메뉴 아이콘
계산기 메뉴 아이콘(30×19)은 위에 이름, 아래에 그림이 있는 모양으로 빌드할 때 자동으로 만들어집니다.
`sets/<id>/icon.json` 로 정합니다: `{"text": "ML MID", "art": "net"}` (그림: `net` 신경망, `gear` 톱니바퀴, `book` 책;
글자는 영문 대문자·숫자 6글자 안팎). 없으면 앱 이름 + 책. 노트 zip 을 덮어써도 지워지지 않습니다.
앱은 종료할 때 `gint_setrestart(1)` 로 OS 메뉴를 직접 띄워서, 나갔다 다시 들어갈 때 열리지 않는 문제를 피합니다.

## Windows 에서 한 번에 빌드 (WSL2)
```
powershell -ExecutionPolicy Bypass -File tools\windows\build_windows.ps1
```
WSL2(Ubuntu) 가 없으면 안내가 나옵니다(`wsl --install -d Ubuntu` 후 재부팅). 처음에는 툴체인 빌드에
30~60분 이상 걸리고, 끝나면 `dist\` 에 세트마다 `.g1a` (예: `mlmid.g1a`, `prodsys.g1a`) 가 생기며 탐색기가 열립니다.
(fxSDK 서버는 git.planet-casio.com 입니다. 실제 PC 에서는 아직 검증하지 못했습니다.)

## 번호 점프 / 색인 링크
- **번호 점프**: 폴더·파일 이름 앞의 숫자(`01_`)가 목록에 `01` 처럼 보입니다. 목록에서 숫자키를
  **두 자리로** 누르면(예: `0` `2`) 그 번호 항목으로 바로 갑니다. EXE 로 엽니다.
- **링크**: 본문 안에 `→폴더번호/파일번호` 또는 `→폴더번호/파일번호:쪽` 을 쓰면(예: `→1/02`, `→1/02:2`)
  그 페이지는 **메뉴 페이지**가 됩니다. 링크 줄 앞에 `>` 가 뜨고(폴더 목록과 같은 방식), ↑ ↓ 로 링크 줄을
  고르고 **EXE** 로 바로 이동합니다. **EXIT / DEL** 로 이전 위치(고르던 줄 그대로)로 돌아오고, **AC** 는
  어디서든 최상위 폴더 목록으로 갑니다. 링크가 있는 페이지는 `>` 칸 때문에 **줄 폭이 122픽셀 이하**여야 합니다.
  링크는 한 페이지에 여러 개(최대 8)여도 되고, 중첩은 6단계까지입니다.
  링크 줄은 `\n` 으로 직접 나눈 줄 기준이므로 한 줄이 화면 폭을 넘지 않게 쓰세요.
- **F2 / F3**: 어디서든(목록·본문) 색인으로 순간이동합니다(위 "색인" 참고). EXIT 로 돌아옵니다.

## 본문에서: 쪽 번호 점프 / 계산기
- **쪽 번호 점프**: 본문에서 숫자키 `1`~`9` 를 누르면 그 쪽으로 바로 갑니다. 없는 쪽 번호는 무시합니다.
  쪽수가 10쪽 이상이면 두 자리로 누르세요(`1` `2` → 12쪽). 없는 쪽 번호는 무시합니다.
- **0 = 계산기**: 본문에서 숫자 `0` 을 누르면 작은 **진짜 계산기**가 뜹니다 (Run-Mat 처럼 한 줄 입력). **EXIT** 로 노트에 돌아옵니다.
  Casio fx-9860GIII 설명서(v3.21)의 계산 규칙을 따릅니다.
  - 키: `0~9 .  + − × ÷  ( )  (−)  x²  ^  EXP  sin cos tan  log ln`, `SHIFT`+`EXP`=π, `SHIFT`+`(−)`=Ans, `SHIFT`+`x²`=√, `SHIFT`+`log`=10^x, `SHIFT`+`ln`=e^x
    (키 위 노란 글자와 같음), `DEL`(또는 `F2`) 한 글자 지움, `AC` 식 지움, `← →` 커서, `↑` 직전 식 불러오기, `F6` Rad/Deg 전환 (기본 Rad, 오른쪽 아래에 RAD/DEG 표시), `EXE` 계산.
    화면은 원래 가짜 화면과 같은 구성입니다: 8px 줄 간격으로 식과 결과 3쌍, 입력 줄(네모 커서), 맨 아래 `JUMP DEL ▶MAT MATH` 기능 줄(스크린샷 비트맵 그대로).
  - 우선순위: 괄호·함수 인수 → x², ^ → (−) → 곱셈 기호 생략(`2π`, `3(5+6)`, `2sin(30)`) → × ÷ → + − (그래서 `6÷2(1+2)=1`, `−2^2=−4`).
  - 표시: 유효숫자 10자리, Norm 1 (`|x|<0.01` 또는 `≥10^10` 이면 `2.5E-03`, `1.2E+12`). 빈 줄에서 `+ − × ÷ ^ x²` 를 누르면 `Ans` 가 앞에 붙습니다.
  - 오류: `Syntax ERROR`(식 오류), `Ma ERROR`(0 으로 나눔, 정의역 밖, 범위 초과). 식은 그대로 두고 고칠 수 있습니다.
  - 한계: 분수 입력·행렬·방정식·통계는 없습니다. 본체와 마지막 자리 반올림이 다를 수 있습니다. 호스트 시험: `gcc -Isrc tools/calc_test.c src/calc_eval.c -o calc_test && ./calc_test`.
  - 한 화면에 최근 계산 3개(식과 결과)와 입력 줄이 보입니다. 앱을 끄기 전까지 Ans 와 최근 식은 유지됩니다.

## 글자 위 모자(ŷ)·막대(ȳ)·화살표(v⃗)
`ŷ` `ȳ` `Ŷ` 처럼 글자 위에 모자(^)나 막대를 씌운 글자를 그대로 쓰면 됩니다. 빌더가 기본 글자 + 결합 문자
(U+0302 모자, U+0304 막대)로 바꾸고, 뷰어가 앞 글자 위에 3픽셀 모양을 그립니다. 결합 문자는 폭이 0이라 줄 폭 계산은
기본 글자 하나와 같습니다. `x̂`(x + U+0302)처럼 결합 문자를 직접 붙여 써도 같게 동작합니다. 수식 줄 안에서도 됩니다.

## 표 줄
한 줄 안에 `│`(U+2502, 상자 세로선)가 있으면 그 줄은 **표의 한 행**이고, 칸은 `│`로 나눕니다. 쪽 안에서 연속된 표 줄이 하나의 표가 됩니다.
```
구분│L1│L2
식│절댓값 합│제곱합 근
효과│희소│매끄러움
```
- 열 폭은 그 열에서 가장 넓은 칸에 맞춰지고, 바깥 테두리·칸 세로선·줄 사이 가로선을 뷰어가 그립니다. 칸 안 글자는 왼쪽 맞춤이고 줄바꿈이 없습니다 (첨자 `_{..}` `^{..}` 가능).
- 높이: 표 한 행 11px, 표 아래에 1px 더. 쪽 높이 합(일반 줄 10px, 수식 줄 22px, 표 행 11px)은 64px 이하여야 합니다 (제목 1줄 + 표 4행, 또는 표 5행).
- 폭: 열 폭 합 + 열 수×3 + 1 이 128px 이하(링크가 있는 쪽은 122px)여야 하고, 열은 6개까지 (권장 3~4개). 표 줄에는 수식(`$`)과 링크를 둘 수 없습니다.
- 표 사이에 일반 줄이 끼면 별개의 표입니다. 검사기가 열 수, 폭, 높이를 확인합니다.

## 그림
노트 안에 `[그림 이름]` 한 줄(줄 전체)을 쓰면 그 자리에 그림이 그려집니다. 그림 파일은 `notes/figures/이름.png`
(흑백, 폭 128px 이하·링크 쪽은 122px 이하, 높이 64px 이하)입니다. 빌드할 때 1비트 비트맵으로 변환해 앱에 넣습니다.
- 그림 높이만큼 쪽 높이를 차지합니다: 제목 줄 10px + 그림 54px 처럼, 쪽 합(일반 줄 10px, 수식 줄 22px, 표 행 11px, 그림 높이)이 64px 이하여야 합니다.
- `python3 tools/fig_tool.py 원본.jpg notes/figures/이름.png` 로 아무 그림이나 128×54 안의 흑백으로 바꿉니다 (`--dither` 로 사진 느낌, 미리보기 출력).
  굵은 선과 단순한 도형이 잘 보이고, 7px 보다 작은 글자는 안 읽히니 설명은 노트 글로 씁니다.
- 검사기는 파일 존재, 폭, 높이, 쪽 높이 합을 확인합니다. 그림 줄에는 링크나 다른 글자를 같이 쓸 수 없습니다.

## 첨자 / 특수문자
- 아래첨자 `_{...}`, 윗첨자 `^{...}` : 예) `a_{n+1}`, `x^{10}`, `e^{-x}`, `H_{2}O`.
  3×5 크기의 작은 글꼴로 그려지고 영문/숫자/`+-=().,/` 만 지원합니다 (중괄호 중첩 불가).
  중괄호 없이 쓴 `_` `^` 는 그냥 글자로 나옵니다. `²` `³` 은 그대로 써도 됩니다.
- 그리스 문자(α β γ θ π …)와 ≤ ≥ ≠ ≈ ∞ ∑ ∫ √ 등은 7px 폰트에 없는 것을 9px 폰트에서 가져와 채웁니다
  (조금 커 보일 수 있음).

## 조작
목록: ↑ ↓ 선택 · 숫자 2자리 점프 · EXE 열기 · F2/F3 색인 · EXIT/DEL 뒤로 · AC 최상위 폴더로 (최상위에서는 EXIT 만 종료)
본문: ← → 페이지 · 숫자 쪽 점프 · 0 계산기 · ↑ ↓ 한 줄 스크롤 (링크 페이지는 링크 줄 선택) · EXE 링크 열기 · F1 쪽번호 · F2/F3 색인 · EXIT/DEL 이전 위치 · AC 최상위 폴더로

## 노트 검사 / 지침
- `python3 tools/check_notes.py` : 줄 폭(128px), 페이지 6줄, 번호 중복, 링크 대상, 폰트에 없는 글자를 검사합니다.
- `docs/PROMPT.md` : 시험 노트를 만들 Claude 프로젝트용 지침(붙여 넣기)과 단계별 요청 프롬프트.

## PC 에서 동작 시뮬레이션 (gint 스텁)
```
gcc -Isrc -Itools/sim -Dmain=app_main tools/sim/sim.c src/main.c src/hangul.c \
    src/font_data.c src/notes.c src/fakecalc.c src/fakecalc_data.c src/calc_eval.c src/calc_ui.c -o sim
mkdir out && ./sim out "0 EXE EXE EXE DOWN DOWN EXE"    # 키: EXIT EXE UP DOWN LEFT RIGHT F1 F2 F3 DEL AC 0-9 DOT EXP NEG PLUS MINUS MUL DIV LP RP SQUARE POWER LOG LN SIN COS TAN (S-EXP = SHIFT+EXP)
python3 tools/sim/sheet.py out sheet.png 3             # 프레임을 한 장으로
```

## PC 에서 미리보기
```
gcc -Isrc tools/host_test.c src/hangul.c src/font_data.c src/notes.c -o host_test
mkdir out && ./host_test out && python3 tools/preview.py out preview.png
```

  폰트 변환·렌더링 로직만 PC 에서 검증했습니다.
